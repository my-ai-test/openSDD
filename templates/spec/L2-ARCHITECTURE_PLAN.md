## 4. 数据流

### 4.1 {{关键写操作流程名称}}

```
用户操作
  → Interface Layer（Controller）
  → Application Service（AS-NN，编排）
  → Domain Layer（BC-NN，聚合根方法，业务规则）
  → Infrastructure Layer（Repository → DB）
  → 聚合根发出领域事件
  → EventBus 分发
  → 消费者 BC（最终一致）
```

### 4.2 {{关键读操作流程名称}}

```
用户查询
  → Interface Layer
  → Application Service（查询编排）
  → Domain Layer 或直接 Read Model（CQRS 场景）
  → Infrastructure Layer（DB / Cache）
```

## 7. 架构适应性函数（Fitness Functions）

> 以下检测在 CI 流水线中自动运行，违反则阻断合并。

| 检测项 | 工具 | 规则 | 触发时机 |
|--------|------|------|---------|
| Domain 层依赖检测 | madge | `domain/` 目录不得 import `infrastructure/` 任何实现类 | PR 合并前 |
| 领域事件注册检测 | 自定义脚本 | EventBus 发布的事件名必须在 DOMAIN_EVENT_CATALOG 中注册 | PR 合并前 |
| 聚合根测试纯净检测 | Jest | `*.aggregate.spec.ts` 中不得出现 DB/HTTP/Redis mock | PR 合并前 |
| 事务边界检测 | 代码审查 | Repository 方法不得同时修改两个不同聚合根（PR 人工检查）| Code Review |
