## 6. 注入防护

| 攻击类型 | 防护措施 |
|---------|---------|
| SQL 注入 | ORM 参数化查询（Prisma/TypeORM），禁止拼接 SQL |
| XSS | 输出转义（React 默认），富文本使用 DOMPurify |
| CSRF | SameSite=Strict Cookie + CSRF Token |
| Prompt 注入 | AI Agent 输入内容经预处理过滤，ACL 层隔离外部内容 |

## 7. DDD 安全边界

> 以下规则基于 DDD 架构的安全设计原则。

| 原则 | 规则 |
|------|------|
| BC 隔离 | 每个 BC 只能读写自己的数据表，禁止跨 BC 直接访问数据库 |
| ACL 防腐 | 所有外部 IAM/IdP 集成必须通过 ACL 层，不得让外部模型污染核心域 |
| 权限检查位置 | 权限校验在 Application Service 层执行，Domain 层不负责权限判断 |
| Agent 隔离 | AI Agent 使用独立 Agent Token，权限范围严格限定（Scope 字段约束） |
