### 1.1 企业字体规范示例（来源：企业设计系统）

> **若企业有统一字体约束，在此声明并要求强制遵守**，其他项目可选遵从。

#### 字号体系

| Token | px | 用途 |
|-------|-----|------|
| F01 | **18px** | 一级页面标题 `.page-title` |
| F02 | **16px** | 二级标题、Section 标题 `.section-title` |
| F03 | **14px** | 三级区块标题、通知正文 |
| F04 | **13px** | 代码名称、工具名等 tertiary |
| F05 | **12px** | **主力字号**：按钮、输入框、导航菜单、表格、标签、Tab |
| F06 | **9px** | 徽标（极小场景）|

#### 字重规则（**只允许 400 / 700**）

| 场景 | 字重 |
|------|------|
| 常规控件文本（按钮 base、输入框、导航菜单、Label、Tab base）| **400** |
| 主要按钮、标题、表格表头、Active Tab、状态指示、名称 | **700** |
| 二级/Section 标题（secondary_title）| **400**（设计系统规范 Regular）|
| ❌ 禁止使用 500 / 600 | — |

#### body 基准（强制）

```css
body {
  font-family: Arial, Helvetica, sans-serif, "Microsoft YaHei", 微软雅黑;
  font-size: 12px;   /* F05 */
  font-weight: 400;
  line-height: 1.5;  /* 12×1.5=18px = F05 段落规范 */
}
```

### 1.2 样式优先级规则

| 优先级 | 用途 | 规则 |
|--------|------|------|
| CSS 自定义属性（token） | 颜色、阴影、圆角 | 用 `var(--xxx)` 引用 |
| 语义化 CSS 类 | 组件视觉 | 优先使用已定义的类名 |
| 内联 `style` | 动态计算值 | 背景色、宽度% 等运行时值 |
| 工具类（Tailwind 等） | 仅用于布局辅助 | **禁止**替代语义化组件类 |


### 4.2 关键布局数值

## 5. 通用 UX 规则

### 5.1 加载状态

| 场景 | 处理方式 |
|------|---------|
| 首屏数据加载 | Skeleton 占位（不使用 spinner）|
| 按钮操作中（API 请求）| 按钮 loading 状态 + 禁用点击 |
| 页面级加载 | 顶部 progress bar |

### 5.2 空状态

| 场景 | 显示内容 |
|------|---------|
| 列表无数据 | 插图 + 说明文字 + 主操作按钮（如"创建第一个 X"） |
| 搜索无结果 | 说明文字 + 清除筛选建议 |
| 权限不足 | 403 插图 + 说明 + 返回首页 |

### 5.3 错误状态

| 场景 | 显示内容 |
|------|---------|
| API 请求失败（5xx）| Toast 错误提示 + 重试按钮 |
| 表单提交验证错误 | 字段级红色错误提示（inline）|
| 资源不存在（404）| 404 页面 + 返回上级 |

### 5.4 表单验证 UX 规则

| 规则 | 说明 |
|------|------|
| 校验触发时机 | 失焦（blur）时触发单字段校验，提交时触发全字段校验 |
| 错误显示位置 | 字段下方，红色文字，`var(--danger)` |
| 必填标记 | 标签右侧红色 `*`（class `req`） |
| 实时字数统计 | 有最大字符限制的文本框显示 `当前/最大` |

## 10. Next.js 实现规范（如使用 Next.js App Router）

### 10.1 路由组结构

```
app/
├── ({{portal}})/          ← {{Portal}} 布局路由组
│   ├── layout.tsx         ← 含 .app > .sidebar + .main > .content 结构
│   ├── {{route}}/
│   │   └── page.tsx
│   └── ...
├── layout.tsx             ← 根布局（html/body/字体）
└── page.tsx               ← redirect('/{{首页路由}}')
```

### 10.2 组件类型规则

| 组件类型 | 指令 | 原因 |
|---------|------|------|
| Layout（Portal） | 无（Server Component）| 不使用 hooks |
| Sidebar / Nav | `'use client'` | 需要 `usePathname()` |
| 含交互的页面 | `'use client'` | 需要 `useState`、`useRouter` |
| 纯展示页面 | 无（Server Component）| 无需 hooks |
