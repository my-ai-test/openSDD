# openSDD V5 多工具迁移执行计划

状态：实现与本地验证完成；Git 暂存/提交因当前仓库 .git 写权限被拒绝而阻塞。环境验证边界见验证日志。每项完成实现、定向验证、问题修复和复验后才进入下一项。

## 范围与验收约定

- 保留 7 个 SDD Skills、规格模板与 Claude 兼容入口；新增 Codex、Kimi Code、OpenCode V1/V2 适配。
- 根 AGENTS.md 按用户原要求保持原文；消费项目的规则另由安装器生成。
- 不修改本机工具的全局配置，不调用付费模型。真实宿主尚未安装/未授权信任的状态必须明确报告，不能伪称端到端通过。
- 验收分为确定性运行时测试、协议适配测试、安装/CLI 集成测试、文档一致性和宿主人工 smoke。前四项必须全部通过；后一项的环境前置条件单独记录。
- 测试目录使用隔离临时项目；安装、升级、卸载都必须保留用户文件和无关配置。

## 问题闭环

每个新问题在 `SDD/02-plans/migration-validation.md` 记录编号、复现、修复、回归结果。缺失宿主或沙箱限制属于验证边界，不能记作通过。

## 最终检查

1. 运行所有 Node 行为测试和文档检查。
2. 运行独立 CLI 与安装器集成验证、PowerShell 语法/包装器验证；在可用环境执行 Bash 检查。
3. 对所有宿主回放同一任务：未就绪拒绝 → 关联规格并完成测试设计 → 允许 → 修改规格后重新拒绝。
4. 运行独立验证器正例和反例，包括 Git base/head 范围。
5. 审核安装、卸载、未知协议、异常退出与状态文件边界。
6. `git diff --check`，审查暂存文件，提交，检查最终 Git 状态及提交 ID。
